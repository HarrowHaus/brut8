# BRUT8

**Raw brutalist pixel UI kit for forged tools.**

A React + TypeScript + Tailwind UI kit with a strong raw aesthetic, dual-surface system (raw/clean), and tool-first philosophy.

See [DESIGN_THESIS.md](DESIGN_THESIS.md) for the full design rationale.

## Features
- Brutalist pixel aesthetic with thick borders, inset shadows, and industrial accents
- Dual surface system (`raw` | `clean`)
- Optional decorative elements (rivets, tape)
- Built on Radix UI for accessibility
- Comprehensive component set for complex tool interfaces

## Getting Started

```bash
npm install
npm run dev
```

The demo showcases the aesthetic with a realistic tool-like dashboard.

## Philosophy
Brut8 is not nostalgia for its own sake. It is a return to the ethics of tool-making — interfaces that feel forged rather than designed.

See the full roadmap in BRUT8_FULL_ROADMAP.md and execution guide in BRUT8_PHASE_EXECUTOR_AGENT.md.
